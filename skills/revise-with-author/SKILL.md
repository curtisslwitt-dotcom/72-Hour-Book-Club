---
name: revise-with-author
description: Apply author feedback to an edited expert guide and secure approval of the exact manuscript version.
---

Start from the stage 4 clean manuscript, its source map and the author review sheet. Accept annotated files, written notes or recorded corrections. Match each change to a chapter, passage and draft version. If notes refer to an older draft, reconcile against the current passage before applying them.

Keep a private revision log with the original wording, requested change, action and source. Apply clear edits directly. If the author changes a decision rule, update every affected example, summary and checklist. Treat new first-person material as author-supplied. Verify external claims separately. Return conflicting instructions or ambiguous numbers as a short written query. Preserve unanswered items for the next round.

Rerun the voice edit on changed passages. Compare the revised manuscript with the reviewed copy and return a clean version, a concise change summary and outstanding decisions. Save the version and mark Awaiting author approval. An approval naming this version closes the stage. Later text edits reopen approval. Forward only the approved master and cleared assets to production.

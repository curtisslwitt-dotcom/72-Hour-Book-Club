---
name: produce-book-files
description: Turn the approved manuscript into the requested ebook or print edition and check the rendered proof.
---

Read the approved master and identify the publisher, requested formats, trim size if printing, author credit, title and available cover assets. Record unknown production choices and complete independent work while awaiting them. Check the chosen publisher's current official format specifications and record the URL and date in the private project.

Build only requested editions. For a reflowable ebook use semantic chapter headings, navigable contents, working notes and accessible image descriptions. For print, lay out the interior at the selected trim, set margins and pagination, and export a print-ready PDF. Prepare the ebook front cover or print wrap using approved artwork. Calculate the print spine from the final interior page count and the publisher's current template. Keep the editable source alongside each export.

Open the actual exports. Compare chapter order, first and last paragraphs, notes and tables with the approved master. Test ebook navigation and inspect narrow and wide views. For print inspect page size, gutter, clipping, image placement, running heads and cover alignment. Record format, filename, version, checks run and unresolved defects. If rendering tools are unavailable mark the affected proof unchecked. Fix defects and regenerate affected files. Route substantive text changes back to author revision. Deliver the proofs, cover and a file manifest to release preparation.

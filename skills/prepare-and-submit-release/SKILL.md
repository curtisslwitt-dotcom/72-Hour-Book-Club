---
name: prepare-and-submit-release
description: Prepare the book listing, obtain release authorization and track submission separately from public availability.
---

Use the approved manuscript version, production manifest and rendered proofs. Draft the listing from the book: title, subtitle, contributor names, description, reader categories and search phrases. Match cover, title page and listing. Collect the author's choices for pricing, territories, release date, rights and identifiers where applicable. Use the publisher's current instructions for required fields and disclosures. Send factual questions to the author.

Present one release sheet with platform, edition, files and versions, metadata, price, distribution choices, proof status and open issues. Save as Ready for release approval only after required fields and proof checks pass. Obtain explicit authorization for the exact edition and settings before submitting. A manuscript approval alone authorizes production. Changed files, prices or territories require updated release approval.

When authorized and platform access is available, check the publisher dashboard for an existing submission of the same edition. Submit once and retain the confirmation, identifier and time. On timeout or uncertain outcome, check the dashboard before retrying. If account-owner action is required, hand off the completed package and identify the exact outstanding action. Record Submitted only with confirmation. Record Live only after verifying the public listing and edition. If the 72-hour target slips, report the actual state, dependency and owner.

# 72 Hour Book Club
Run the four skills in order. On restart, read the project checkpoint and resume the first incomplete stage. Keep each author's research, recordings, transcript and manuscript in their private project, outside this public repository. The repository holds reusable instructions only.

1. [Research the field](skills/research-the-field/SKILL.md)
2. [Select Money Dialogs and prepare the recording worksheet](skills/prepare-recording-worksheet/SKILL.md)
3. [Outline and write](skills/outline-and-write/SKILL.md)
4. [Edit in the expert's voice](skills/edit-expert-voice/SKILL.md)

Claude plugin handoff: expose one start command and one resume command. Start runs stages 1 and 2. Resume takes one or more recordings or transcripts and the saved project, runs stages 3 and 4, and returns the edited manuscript for author review. Save input versions and completed outputs after each stage. Preserve prior versions when the author submits corrections. Target recordings by hour 24, an edited first draft by hour 48 and submission by hour 72 subject to author edits, approval and release arrangements. These are elapsed-time targets from kickoff. Publication is a separate authorized action.

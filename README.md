# 72 Hour Book Club
Run the seven skills in order. On restart, read the project checkpoint and resume the first incomplete stage. Keep each author's research, recordings, transcript and manuscript in their private project, outside this public repository. The repository holds reusable instructions only.

1. [Research the field](skills/research-the-field/SKILL.md)
2. [Select Money Dialogs and prepare the recording worksheet](skills/prepare-recording-worksheet/SKILL.md)
3. [Outline and write](skills/outline-and-write/SKILL.md)
4. [Edit in the expert's voice](skills/edit-expert-voice/SKILL.md)
5. [Revise with the author](skills/revise-with-author/SKILL.md)
6. [Produce and proof the book files](skills/produce-book-files/SKILL.md)
7. [Prepare and submit the release](skills/prepare-and-submit-release/SKILL.md)

On author feedback, resume stage 5. On manuscript approval, run stage 6 and prepare the stage 7 release sheet. On release authorization, continue stage 7 for the approved edition. Keep each status and its evidence in the private project checkpoint.

Claude plugin handoff: expose one start command and one resume command. Start runs stages 1 and 2. Resume accepts existing articles and written expert answers, or recordings and transcripts, alongside the saved research and selected questions. The writing skill develops all 30 decisions at article depth and targets a 35,000–45,000-word first manuscript when supported. The editing skill verifies coverage before human review. Resume then uses these materials, runs stages 3 and 4, and returns the edited manuscript for author review. Save input versions and completed outputs after each stage. Preserve prior versions when the author submits corrections. Target recordings by hour 24, an edited first draft by hour 48 and submission by hour 72 subject to author edits, approval and release arrangements. These are elapsed-time targets from kickoff. Publication is a separate authorized action.
